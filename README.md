# Student Performance Data Collection System

## 📌 Project Overview

The Student Performance Data Collection System is a web-based application developed using Python Flask and SQLite. It helps collect, manage, and analyze student performance details through a simple and user-friendly interface.

## 🎯 Features

- Add new student details
- View student records
- Search student information
- Edit student details
- Delete student records
- Dashboard with performance analytics
- Export student data to CSV
- Student performance prediction

## 🛠️ Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS

## ⚙️ Installation and Setup

**Step 1: Clone the repository**

```bash
git clone https://github.com/maha2403/Student-Performance-Data-Collection-System.git
```

**Step 2: Open the project folder**

```bash
cd Student-Performance-Data-Collection-System
```

**Step 3: Install Flask**

```bash
pip install flask
```

**Step 4: Run the application**

```bash
python app.py
```

**Step 5: Open in browser**

```text
http://127.0.0.1:5000/
```

## 💡 Project Objective

The main objective of this project is to simplify student data management and provide useful insights into student academic performance.
